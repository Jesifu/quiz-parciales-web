# Quiz · Preguntas de Parciales

Quiz interactivo multiple-choice con preguntas del banco de parciales de **Desarrollo y Arquitecturas Web** (Prof. Claudio Milio).

## Cómo usarlo

Abrir `index.html` con doble click en el navegador. Funciona sin servidor (`file://`).

## Contenido

43 preguntas organizadas en 6 bloques:

1. Redes, arquitecturas y sistemas
2. HTML, formularios y DOM
3. XML, DTD y XML Schema
4. ASP / ASP.NET y modelo de objetos
5. Estado, cookies y configuración
6. Criptografía

## Funcionalidades

- 4 opciones por pregunta con feedback inmediato (verde/rojo).
- Explicación completa después de responder (con tablas, código y comparaciones).
- El orden de las opciones se mezcla automáticamente.
- Filtros: por bloque temático y por estado (todas / sin responder / solo erradas).
- Progreso persistente en `localStorage` (sobrevive al cerrar el navegador).
- Atajos de teclado: `1/2/3/4` o `A/B/C/D` para responder, `←/→` para navegar.
